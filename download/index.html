Linux packages

Packages are provided for Mending Wall, Doxide and Birch, for x86-64 (AMD64) and AArch64 (ARM64) architectures. Choose your Linux distribution below for instructions.

Add the repository:

echo 'deb http://download.indii.org/deb resolute main' | sudo tee /etc/apt/sources.list.d/indii.org.list
curl -fsSL https://download.indii.org/deb/Release.key | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/indii.org.gpg > /dev/null
sudo apt update

Then install desired packages:

sudo apt install mendingwall doxide birch

Mending Wall is unavailable as a newer version of libadwaita is required. It is available on Debian 13.

Add the repository:

sudo dnf config-manager addrepo --from-repofile=https://download.indii.org/rpm/fedora/44/indii.org.repo
sudo dnf update

Then install desired packages:

sudo dnf install mendingwall doxide birch
